## 13.1 確定済みの方針

| 項目 | 現在の決定 |
|------|------------|
| LabVIEW | 64bit版 |
| TestStand | LabVIEW Adapterから1イベント1VIを呼ぶ |
| RAMScope実装 | **RAMScopeVP API 64bit版をCLFNで直接呼ぶ** |
| RAMScope接続 | USB3.0 |
| RAMScope API DLL | `RAMScopeVP_API_x64.dll` |
| RAMScopeライフサイクル | GT150共通関数をGT170でも使用 |
| エラー処理 | 標準error cluster + Status + TestError + API ReturnCode変換 |
| 安全停止 | TestStand Cleanupで高圧停止を最優先 |

### 現在のRAMScope実装ルート

```text
10A 環境準備・DLL疎通・Connect PoC
  → 10B 共通エラー変換・各VI作成
  → LabVIEW Flow Test
  → 11 TestStand組み込み
  → 12 異常系・Cleanup検証
```

過去の「API直呼びと市販ドライバを比較してから決定」「64bit DLLの入手可否を確認」という工程は完了済みであり、今後の作業項目から除外する。
