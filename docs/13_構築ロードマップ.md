## 13.1 確定済みの方針

| 項目 | 現在の決定 |
|---|---|
| LabVIEW | 64bit版 |
| RAMScope実装 | RAMScopeVP API 64bit版をCLFNで直接呼ぶ |
| RAMScope接続 | USB3.0 |
| API DLL | `RAMScopeVP_API_x64.dll` |
| DLL層 | 1関数 = 1薄い`RS_DLL_*`ラッパVI |
| Data Conversion層 | typedef、数値変換、Builder、ParserをDLLから分離 |
| 公開層 | 1イベント = 1`RAMScope_*`公開API VI |
| 単体確認 | `PoC_RAMScope_Main.vi`でTestStandなしの通し確認を先に行う |
| CAN | RAM計測PoC後に方式を確定し、採用方式だけ実装する |
| TestStand | RAM/CAN単体PoC後に公開APIを呼ぶ |
| エラー処理 | CLFN error cluster + API ReturnCode変換 + Status/TestError |
| 安全停止 | TestStand Cleanupで高圧停止を最優先 |
