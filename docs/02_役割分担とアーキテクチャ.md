# 02. 役割分担とアーキテクチャ

## 2.1 LabVIEW と TestStand の役割分担

| 項目 | LabVIEW | TestStand |
|------|---------|-----------|
| 担当 | **個々の機器操作** | **試験全体のフロー管理** |
| 粒度 | ms オーダー（最小 1ms）の即応制御・計測 | 試験イベントの順序・条件・タイミング |
| 状態 | 各機器の状態取得 | 試験条件・結果の管理／可視化 |
| 内容 | 1機器1操作の VI（例：計測開始、電圧設定） | 同期／非同期制御、条件分岐、待ち時間、再利用 |

### 切り分けの原則

- **「即応する最小の操作」は LabVIEW VI**。VI 内には複雑な待ち時間・条件分岐を作り込まない。
- **「いつ・どの順番で・どの条件で実行するか」は TestStand**。
- 内部待ち時間も原則 TestStand 側で管理する（VI に `Wait(ms)` を埋め込まない）。
  → これにより同期・非同期・条件分岐・待ち時間を TestStand 側で明示的に設計できる。

```
TestStand（試験フロー）
  ├─ Step1: 低圧電源ON         → call PPX_Voltage_Set.vi
  ├─ Step2: RAMScope計測開始    → call RAMScope_Log_Start.vi
  ├─ Step3: 高圧電源 電圧設定   → call RZX_Voltage_Set.vi
  ├─ Step4: 負荷電流ランプ(非同期)→ call Load_Current_Ramp.vi  ← 別スレッドで実行
  ├─ Step5: (ランプ中に)CANモード送信 → call CAN_Send_Mode.vi
  ├─ Step6: 待ち / 条件分岐
  └─ Cleanup: 安全順序でシャットダウン
```

## 2.2 同期／非同期を使い分ける理由

自動試験には「順番を守るべき操作」と「同時に処理したい動作」が混在している。

| 方式 | 問題点 |
|------|--------|
| すべて同期 | 実機と異なる挙動になる（本来並行する動作が直列化される） |
| すべて非同期 | 再現性が低下する（タイミングが安定しない） |

→ **操作の性質に応じて同期／非同期を使い分ける。**

### 例：負荷電流は非同期で制御

- 負荷電流の変化（ランプ）は、**動作が終わりきるまで次の動作を待つ必要がない**。
- そのため負荷電流ランプは **非同期** で開始し、
  ランプ進行中に **モード遷移などの処理を割り込ませる（非同期処理）**。
- 一方、「電源 ON → マイコン起動確認 → 計測開始」のように
  **順序を守るべき操作は同期** で実行する。

> 実装：負荷電流ランプ VI は「変化中に他処理の割り込みが可能な設計（並列処理）」とする。
> 詳細は [07_負荷電流VIと並列処理.md](./07_負荷電流VIと並列処理.md)。

## 2.3 再利用性の確保（設計方針）

- **1イベント1VI** とし、TestStand 側でステップの並び替え・流用を容易にする。
- 試験条件（電圧・電流・モード番号・Ramp 時間・使用台数 等）は **すべて変数化** し、
  TestStand のパラメータ／変数として渡す。VI 内にハードコードしない。
- イベント単位の VI を組み合わせることで、別試験への流用を容易にする。

## 2.4 全体アーキテクチャ図

```
┌──────────────────────── TestStand ────────────────────────┐
│  MainSequence                                              │
│   ├ Setup        : 機器接続・初期化（リファレンス確立）       │
│   ├ Main         : サブシーケンス呼び出しで試験手順を構成      │
│   │    ├ SubSeq_電源投入                                    │
│   │    ├ SubSeq_計測開始                                    │
│   │    ├ SubSeq_負荷シナリオ（同期/非同期混在）              │
│   │    └ SubSeq_計測停止・保存                              │
│   └ Cleanup      : 安全シャットダウン（異常時も必ず実行）     │
│                                                            │
│  変数（試験条件）: FileGlobals / Parameters                 │
│   - 電圧条件, 電流条件, 制御モード番号, Ramp時間, 使用台数 等 │
└────────────────────────────┬───────────────────────────────┘
                             │ LabVIEW Adapter（VI Call）
┌────────────────────────────▼───────────────────────────────┐
│  LabVIEW VI 群（1イベント1VI）                              │
│   入力: 条件値（電圧/電流/モード/Ramp...） + リファレンス     │
│   出力: 実行結果ステータス + エラー情報 + 計測値             │
└─────────────────────────────────────────────────────────────┘
```
