# 01. システム概要と構成

> **本章の役割**：何を自動化し、どの機器をどの接続方式で使用するかを定義する。
>
> 本章は設計概要であり、具体的な画面操作やVI配線の正本ではない。操作手順は各実装章と[00A](./00A_LabVIEW実装資料の記述ルール.md)に従う。実装の読み順は[README](../README.md)を正とする。
>
> **2026-07-26更新**：採用Versionと仕様根拠は[00C](./00C_一次資料とバージョン基準.md)へ集約した。機器一覧と接続方式は維持し、未入手の通信仕様を推測で補わない。

## 1.1 目的

NI社製LabVIEWとTestStandを利用し、複数の電源・測定器・CAN機器を連携させる自動テストシステムを構築する。

## 1.2 背景

- 複数の操作者が、模擬電源、供試体マイコンのCAN操作、測定機器の操作を分担している。
- 操作タイミングがシビアな試験では、人手による入力タイミングの調整と試行錯誤が発生している。
- 試験条件ごとの設定変更忘れ、計測開始忘れ、保存忘れにより再試験が発生している。

## 1.3 導入効果

| ソフト | 担当 | 効果 |
|---|---|---|
| LabVIEW | 個々の機器操作 | 機器操作をVI化し、設定・開始・停止・読み出しを再現可能にする |
| TestStand | 試験全体のフロー | 条件、順序、待ち、分岐、繰り返し、結果、Cleanupを一元管理する |
| 組み合わせ | 自動試験 | 人に依存した操作を再現性の高いシーケンスへ置き換える |

## 1.4 計測・制御対象機器

| 区分 | 役割 | 型式 | 接続 | 実装方式 |
|---|---|---|---|---|
| 測定 | 電圧・電流計測 | DLM5058（横河） | Ethernet | VISA / 計装ドライバ |
| 測定 | 温度ロガー | MX100（横河） | Ethernet | 専用APIまたは計装ドライバ |
| 測定/制御 | RAM計測、CAN候補 | RAMScope GT170 | **USB3.0** | **RAMScopeVP API 64bit版をCLFNで呼び出す** |
| 電源 | 高圧模擬電源 | RZ-X2-100K-H × 最大3台 | Ethernet | SCPI / VISA |
| 電源 | 高圧負荷電源 | RZ-X2-100K-H × 最大3台 | Ethernet | SCPI / VISA |
| 電源 | DUT低圧電源 | PPX36-3 | Ethernet | 公式ドライバまたはSCPI |
| 電源 | IGS電源 | PPX36-3 | Ethernet | 公式ドライバまたはSCPI |
| CAN | 供試体マイコンCAN操作 | CANalyzer / USB-CAN / NI-XNET / RAMScope CAN | 各方式 | [09](./09_CAN通信の実装.md)で最終選定 |

### RAMScopeの採用方式

RAMScopeVP APIはC言語用DLLであり、LabVIEW用の完成VIではない。C関数、構造体ポインタ、生バイト列をLabVIEWから扱うため、DLLラッパ、Builder、Parser、公開APIへ責務を分ける。詳細な採用理由とVI構成は[10](./10_RAMScope実装方針.md)を参照する。

```text
LabVIEW 64bit
  → ライブラリ関数呼び出しノード（Call Library Function Node）
    → RAMScopeVP_API_x64.dll
      → GT170_x64.dll / GT170USB_x64.dll
        → RAMScope GT170（USB3.0）
```

- 32bit版DLLは使用しない。
- API直呼び方式を採用する。
- 環境準備からPoCまでの詳細は第10章だけを参照する。

## 1.5 接続構成

### Ethernet接続

オシロ、ロガー、高圧電源、低圧電源は固定IPを設定し、制御PCと同一サブネットへ配置する。

| 機器 | 型式 | IPアドレス例 | VISAリソース名例 |
|---|---|---|---|
| オシロ | DLM5058 | `192.168.0.11` | `TCPIP0::192.168.0.11::inst0::INSTR` |
| ロガー | MX100 | `192.168.0.12` | 専用API仕様に従う |
| 高圧模擬1～3 | RZ-X2-100K-H | `192.168.0.21`～`23` | 実機通信仕様に従う |
| 高圧負荷1～3 | RZ-X2-100K-H | `192.168.0.31`～`33` | 実機通信仕様に従う |
| DUT低圧 | PPX36-3 | `192.168.0.41` | 実機通信仕様に従う |
| IGS | PPX36-3 | `192.168.0.42` | 実機通信仕様に従う |

### RAMScope接続

- GT170を制御PCへUSB3.0で直結する。
- GT170U01のEthernetポートは本API制御用の接続先として扱わない。
- RAMScopeはLAN機器ではないためIP割り当て表へ含めない。
- 接続確認は純正RAMScopeVP、Windowsデバイスマネージャー、`Test-RAMScopeDll.ps1`、`RAMScope_Connect.vi`の順で行う。

## 1.6 自動化の対象

- 電源制御
- CAN信号制御
- 負荷電流ランプ
- オシロ波形取得・保存
- 温度ロギング
- RAMScopeの接続、初期化、設定、計測開始、データ取得、停止、終了
- 試験条件、結果、エラー、保存ファイルの関連付け

試験条件を変更しても、VIを作り直さずTestStand変数とシーケンス構成の変更で再利用できる設計とする。
