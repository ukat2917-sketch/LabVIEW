# 付録 A1. FG420 を用いた基盤単体試験 自動化手順（VI / TestStand）

別案件「**ファンクションジェネレータ FG420 を使った基盤単体試験用の自動化システム**」の
構築手順書（付録）。LabVIEW VI の作り方と TestStand シーケンスの設定手順を示す。

> 本付録は本編（[04](./04_VIの仕組み_LabVIEW基礎.md)〜[13](./13_構築ロードマップ.md)）の設計方針
> （1イベント1VI、入出力・エラー共通仕様、TestStand での条件管理）を**そのまま流用**する。
> 重複する基礎説明は本編を参照し、ここでは **FG420 固有の手順**に絞る。

> **コマンド表記についての注意**：本付録作成時、機器マニュアル
> **`IMFG410-63JA`（FG410/FG420 通信インタフェース）** は配信元がネットワーク制限で参照できなかった。
> そのため SCPI コマンド例は **横河 FG400 系の一般的な表記に基づく「雛形」**であり、
> **正確な命令ニーモニックは必ず `IMFG410-63JA` の通信コマンド章で確定**すること。
> なお **FG420 は LabVIEW ドライバが提供**されているため、本付録は**ドライバ利用を主**とする
> （ドライバが命令の差異を吸収するため、SCPI の細部に依存しない）。

---

## A1.1 目的と対象

- **目的**：FG420 が出力する信号（正弦波・方形波・パルス等）を試験条件どおりに自動設定・出力し、
  **基盤（基板）単体の入出力特性を再現性高く試験**する。
- **対象機器**：横河 **FG420**（アービトラリ／ファンクションジェネレータ、**2 チャネル**）。
  - 兄弟機 FG410 は 1 チャネル。**FG420 は 2ch** のため、**チャネル指定**が要点（A1.4）。
  - 主な波形：正弦波・方形波・パルス・ランプ・パラメータ可変波形・ノイズ・DC・任意波形。
- **試験の基本形**：FG420 で **刺激信号を印加** → 基盤の応答を測定器（オシロ等）／基盤自身で取得 →
  TestStand で **合否判定**。試験条件を変えて再利用できるシーケンスにする。

---

## A1.2 機器構成とインタフェース

| 項目 | 内容 |
|------|------|
| 機器 | FG420（2ch ファンクションジェネレータ） |
| リモート I/F | **USB（USBTMC）** および **GP-IB**（いずれも標準のプログラマブル I/F） |
| 制御方法 | **① 横河提供 LabVIEW ドライバ（推奨）** / ② SCPI を VISA で直接送信 |
| ドライバ | 横河 Web サイトから **LabVIEW ドライバ**／LabWindows/CVI ドライバを入手可 |
| VISA リソース例 | USB：`USB0::0x0B21::0x****::<SERIAL>::INSTR`（横河ベンダ ID は `0x0B21`）<br>GPIB：`GPIB0::<アドレス>::INSTR` |

> **Ethernet 可否は要確認**：FG400 系の標準リモートは USB / GP-IB。Ethernet 制御の可否は
> `IMFG410-63JA` および機器仕様で確認する（本編の Ethernet 機器とは接続形態が異なる前提）。

## A1.3 環境構築（着手前の準備）

本編 [03_LabVIEW環境構築.md](./03_LabVIEW環境構築.md) と同じ要領で行う。FG420 固有点のみ記載。

1. **NI-VISA** をインストール（USBTMC / GPIB を VISA で扱う基盤）。
2. **FG420 の LabVIEW ドライバ**を横河サイトから入手し、`instr.lib` に配置
   （または VI Package Manager / 提供インストーラで導入）。本編 [03](./03_LabVIEW環境構築.md) 3.3 の
   バージョン互換性の考え方（古い対応表記でも新 LabVIEW で再コンパイルされる）も同様に適用。
3. **接続確認**：
   - USB 接続なら NI MAX に USBTMC デバイスとして見えること、GPIB ならアドレスが見えることを確認。
   - `Open VISA Test Panel` から **`*IDN?`** を送り、機器識別文字列が返ることを確認。
   - 返れば通信 OK。VISA リソース名を記録（A1.2 の形式）。
4. ビット数（32/64bit）を LabVIEW・Runtime・ドライバで揃える。

## A1.4 FG420 制御 VI の設計方針

本編 [05_VI設計方針と共通仕様.md](./05_VI設計方針と共通仕様.md) の共通仕様に準拠する。FG420 固有の要点：

### チャネル指定（2ch）
- FG420 は 2ch のため、**ほぼ全ての操作 VI に「チャネル番号（1/2）」入力**を持たせる。
- ドライバ利用時はドライバの ch 引数を、SCPI 直叩き時は **チャネル指定構文**（例：`SOURce1` / `SOURce2`、
  または `:CHANnel1` 等。**正確な構文はマニュアルで確定**）を使う。
- 2ch を独立に使う／位相同期させる場合は、その設定 VI（位相・同期）も用意する。

### 共通入出力（本編 5.2 に準拠）
| 区分 | 端子 |
|------|------|
| 入力 | 機器リファレンス in、**チャネル番号**、試験条件（波形種別・周波数・振幅・オフセット・位相・バースト等）、error in |
| 出力 | 機器リファレンス out、実行結果ステータス（`Status.ctl`）、エラー情報（`TestError.ctl`）、（必要時）設定値読み戻し、error out |

- **試験条件は TestStand 側で変数管理**（波形・周波数・振幅などを変数化し、条件ごとに変更可能に）。
- **内部待ち時間は VI に埋め込まない**（同期／待ちは TestStand 側、本編 [11](./11_TestStandシーケンス構築手順.md)）。

## A1.5 作成する VI 一覧（1イベント1VI）

| VI | 役割 | 主な入力 |
|----|------|----------|
| `FG420_Init.vi` | 接続・初期化（`*IDN?` 確認、`*RST` 任意） | リファレンス |
| `FG420_Config_Waveform.vi` | 波形種別の設定（Sine/Square/Pulse/Ramp/Noise/DC/Arb） | ch、波形種別 |
| `FG420_Set_Frequency.vi` | 周波数設定 | ch、周波数[Hz] |
| `FG420_Set_Amplitude.vi` | 振幅（出力レベル）設定 | ch、振幅 |
| `FG420_Set_Offset.vi` | DC オフセット設定 | ch、オフセット |
| `FG420_Set_Phase.vi` | 位相設定（2ch 位相関係用） | ch、位相 |
| `FG420_Config_Burst.vi` | バースト／トリガ設定（必要時） | ch、バースト条件 |
| `FG420_Output_On.vi` | 出力 ON | ch |
| `FG420_Output_Off.vi` | 出力 OFF | ch |
| `FG420_Read_Setting.vi` | 設定値の読み戻し（検証用） | ch |
| `FG420_Close.vi` | セッション解放 | リファレンス |

> ドライバ利用時は、1 つのドライバ VI で複数設定をまとめられる場合があるが、
> **本資料の方針（1イベント1VI）に合わせて粒度を分けて**おくと、TestStand での並び替え・流用が容易。

## A1.6 VI の作り方（2 通り）

本編 [06_VIの作り方_手順.md](./06_VIの作り方_手順.md) の手順をベースに、FG420 では次のどちらかで中身を作る。

### 方式A：横河 LabVIEW ドライバを使う（推奨）
1. テンプレート VI（本編 6.6）を複製。
2. ブロックダイアグラムに、対応するドライバ VI（例：周波数設定・出力 ON など）を配置。
3. 入力（ch・条件値）をドライバ VI の対応端子へ配線。
4. ドライバのエラー出力を `TestError.ctl` / `error out` に変換。
5. コネクタペインに入出力を割り当て（本編 6.4。**全 VI で並びを統一**）。

### 方式B：SCPI を VISA で直接送る（ドライバが無い／不足する場合）
1. `error in` を Case ストラクチャでガード（No Error 時のみ実処理）。
2. `Format Into String` で SCPI 文字列を生成（**下表は雛形。要マニュアル確認**）。
3. `VISA Write` で送信、設定確認が必要なら `*OPC?` 等を `VISA Read`。
4. `SYSTem:ERRor?`（または機器のエラー照会）で異常を確認 → `TestError.ctl` に反映。

#### SCPI コマンド対応表（雛形：**正確な表記は `IMFG410-63JA` で確定**）

| 操作 | 一般的な SCPI 例（要確認） | 備考 |
|------|----------------------------|------|
| 機器識別 | `*IDN?` | IEEE488.2 共通 |
| リセット | `*RST` | 共通 |
| 同期確認 | `*OPC?` | 共通 |
| エラー照会 | `SYSTem:ERRor?` | 共通系 |
| チャネル指定 | `SOURce1:` / `SOURce2:`（または `CHANnel1` 等） | **FG420 の 2ch 指定構文は要確認** |
| 波形種別 | `SOURce<ch>:FUNCtion {SIN\|SQU\|PULS\|RAMP\|NOIS\|DC\|ARB}` | キーワードは要確認 |
| 周波数 | `SOURce<ch>:FREQuency <値>` | 単位・分解能は仕様参照 |
| 振幅 | `SOURce<ch>:VOLTage <値>`（または `:AMPLitude`） | 単位（Vpp 等）要確認 |
| オフセット | `SOURce<ch>:VOLTage:OFFSet <値>` | 要確認 |
| 位相 | `SOURce<ch>:PHASe <値>` | 2ch 位相関係 |
| 出力 ON/OFF | `OUTPut<ch> {ON\|OFF}` | 要確認 |
| バースト | `SOURce<ch>:BURSt:...` / トリガ系 | 必要時 |

> ⚠️ 上表のニーモニックは**確定値ではない**。横河 FG 系は SCPI 準拠だが命令の綴り・階層が
> 機種で異なるため、**送信前に必ず実機 `*IDN?` 応答とマニュアルで照合**すること。
> 確定後、この表を実コマンドで上書きして「確定版」にする。

## A1.7 TestStand シーケンス構築手順

本編 [11_TestStandシーケンス構築手順.md](./11_TestStandシーケンス構築手順.md) に準拠。FG420 案件での進め方：

1. **LabVIEW Adapter** を設定し、A1.5 の VI を呼べるようにする。
2. **試験条件を変数化**（FileGlobals / Parameters）：
   - `波形種別`、`周波数`、`振幅`、`オフセット`、`位相`、`チャネル`、`判定しきい値` 等。
   - 条件を CSV / プロパティファイルで管理し、`Property Loader` で読み込むと条件変更が容易。
3. **イベント単位のサブシーケンス化**（本編 11.5）：
   - `SubSeq_FG設定`（波形→周波数→振幅→オフセット→（位相））
   - `SubSeq_出力ON`
   - `SubSeq_応答測定`（オシロ等で取得、または基盤からの読み出し）
   - `SubSeq_判定`
   - `SubSeq_出力OFF`
4. **MainSequence** で `Sequence Call` により順序を構成。条件で並び替え・流用。
5. **合否判定**：測定値と `判定しきい値` を比較し、ステップの Status（Pass/Fail）を設定。
6. **同期／非同期・待ち**は TestStand 側で明示（出力安定待ち等は `Wait` ステップ）。
7. **レポート**：試験条件・設定値・測定値・合否を記録（本編 11.7）。

## A1.8 基盤単体試験の典型フロー（例）

```
Setup    : FG420_Init（*IDN?確認） / 測定器Init / 条件ロード
Main
  ├ SubSeq_FG設定(ch, 波形, 周波数, 振幅, オフセット)
  ├ SubSeq_出力ON(ch)
  ├ Wait（出力・基盤の安定待ち：時間は条件変数）
  ├ SubSeq_応答測定（オシロ波形 / 基盤の出力値取得）
  ├ SubSeq_判定（測定値 vs しきい値 → Pass/Fail）
  └ SubSeq_出力OFF(ch)
Cleanup  : FG420_Output_Off（全ch） / FG420_Close / 測定器Close   ← 異常時も必ず実行
```

- 複数条件（周波数スイープ等）は、条件配列で **For ループ**または条件ファイルで回す。
- 2ch を使う試験は、ch1/ch2 それぞれに設定・出力 ON/OFF を行い、必要なら **位相同期**を設定。

## A1.9 異常系・安全

本編 [12_異常系処理とシャットダウン設計.md](./12_異常系処理とシャットダウン設計.md) の考え方を適用。

- **Cleanup で必ず `FG420_Output_Off`（全ch）→ `FG420_Close`** を実行（異常終了でも出力を残さない）。
- 基盤に過大入力を与えないよう、**振幅・オフセットの上限を試験条件側でガード**（範囲チェック）。
- 異常時のエラー情報（機器名 `FG420`・コード・メッセージ）を `TestError.ctl` で TestStand へ。

## A1.12 未確定事項（要確認）

- FG420 の **正確な SCPI コマンド体系**（チャネル指定・波形キーワード・振幅単位等）。
- **Ethernet 制御の可否**（標準は USB / GP-IB）。
- LabVIEW ドライバの **対応機能範囲**（任意波形・バースト・シーケンス機能をどこまで VI 化できるか）。
- 任意波形／シーケンス運用が必要な場合の **Sequence Edit Software** 併用要否。
