# 06. 機器別 VI 構築手順

各機器の制御 VI の作り方を機器ごとにまとめる。
共通の入出力仕様・エラー処理は [04](./04_VI設計方針と共通仕様.md) / [05](./05_VIの作り方_手順.md) を前提とする。

> 実際の通信コマンド（SCPI 等）は機器のプログラミングマニュアルに従うこと。
> 本書のコマンド例は構築イメージを示すもの。

---

## 6.1 オシロスコープ DLM5058（横河）— 電圧・電流計測

**接続**：Ethernet（VISA TCPIP / LXI）

**作る VI**

| VI | 処理概要 |
|----|----------|
| `DLM5058_Init.vi` | VISA Open、`*IDN?` 確認、初期設定（時間軸・チャンネル） |
| `DLM5058_Config.vi` | レンジ・カップリング・トリガ条件を試験条件に応じ設定 |
| `DLM5058_Acquire_Start.vi` | 取り込み開始（`:STARt` 等） |
| `DLM5058_Acquire_Stop.vi` | 取り込み停止（`:STOP`） |
| `DLM5058_Save_Waveform.vi` | 波形データを取得・ファイル保存（CSV/バイナリ） |

**手順**
1. NI MAX で VISA リソースを確認（[03](./03_LabVIEW環境構築.md)）。
2. 計装ドライバが提供されていればそれを利用。無ければ SCPI を VISA Write/Read。
3. 波形保存 VI は **ファイル名に試験条件・日時を含める**（例：`<試験ID>_<条件>_<日時>.csv`）。
4. 異常系：エラー発生後に計測中の場合は **計測停止 → エラーと分かる名前でデータ保存**
   （[11](./11_異常系処理とシャットダウン設計.md)）。

## 6.2 温度ロガー MX100（横河）

**接続**：Ethernet

**作る VI**

| VI | 処理概要 |
|----|----------|
| `MX100_Init.vi` | 接続・チャンネル設定 |
| `MX100_Log_Start.vi` | ロギング開始 |
| `MX100_Log_Stop.vi` | ロギング停止 |
| `MX100_Save.vi` | 取得データの保存 |

**手順**
1. MX100 は横河の専用通信／API（MX100 用ライブラリ）または計装ドライバを利用。
2. ロガーも異常系では「計測停止 → エラー名で保存」を行う（解析用に異常時信号を残す）。

## 6.3 RAMScope GT170（CAM モジュール付）— RAM 計測 / CAN

**接続**：専用 IF / Ethernet（型式により異なる）

**作る VI**

| VI | 処理概要 |
|----|----------|
| `RAMScope_Init.vi` | API/ドライバ初期化、測定変数（RAM アドレス）設定 |
| `RAMScope_Log_Start.vi` | RAM 計測開始 |
| `RAMScope_Log_Stop.vi` | RAM 計測停止 |
| `RAMScope_Read.vi` | 現在の RAM 値取得 |
| `RAMScope_Reset.vi` | **異常時のリセット（最後に実行）** |

**手順／注意**
- RAMScope は LabVIEW から **API（DLL）呼び出し** か **マックシステムズ製ドライバ** で制御する。
  方式選定は [09_RAMScope実装方針.md](./09_RAMScope実装方針.md) を参照。
- 異常系：エラー時は **一番最後に RAMScope をリセット**。
  順序は「DUT の電源を落としてから RAMScope を落とす」（[11](./11_異常系処理とシャットダウン設計.md)）。

## 6.4 高圧模擬電源 / 高圧負荷電源 RZ-X2-100K-H

**接続**：Ethernet。**出力により接続台数が変わる（×3 等）**。

**作る VI**

| VI | 処理概要 |
|----|----------|
| `RZX_Init.vi` | 接続・初期化（台数分） |
| `RZX_Voltage_Set.vi` | 電圧設定（試験条件＝電圧条件） |
| `RZX_Current_Limit_Set.vi` | 電流制限設定 |
| `RZX_Output_On.vi` | 出力 ON |
| `RZX_Output_Off.vi` | 出力 OFF |
| `RZX_Read.vi` | 出力電圧・電流のモニタ |

**手順／注意**
- **複数台対応**：使用台数を入力（試験条件の「使用台数」変数）で受け取り、
  リファレンス配列に対して For ループで設定する設計にする。
  → 出力に応じて台数が変わっても同じ VI で対応できる。
- 並列・同期運転（マスタ/スレーブ）構成の場合、メーカー仕様に従い設定順序を守る。
- **異常系：高圧系は一番はじめに落とす**（大きな事故につながる可能性があるため）。
  Cleanup の先頭で `RZX_Output_Off.vi`（[11](./11_異常系処理とシャットダウン設計.md)）。

## 6.5 低圧マイコン制御電源 / IGS 電源 PPX36-3

**接続**：Ethernet（LXI/SCPI）

**作る VI**

| VI | 処理概要 |
|----|----------|
| `PPX_Init.vi` | VISA Open、`*IDN?`、初期設定 |
| `PPX_Voltage_Set.vi` | 電圧設定（例：`SOUR:VOLT <V>`） |
| `PPX_Current_Limit_Set.vi` | 電流制限設定（例：`SOUR:CURR <A>`） |
| `PPX_Output_On.vi` | 出力 ON（例：`OUTP ON`） |
| `PPX_Output_Off.vi` | 出力 OFF（例：`OUTP OFF`） |
| `PPX_Read.vi` | 電圧・電流モニタ（例：`MEAS:VOLT?` / `MEAS:CURR?`） |

**手順／注意**
- 低圧は DUT（マイコン）の電源。**異常系では高圧停止後に停止**する。
  （マイコンが死んで高圧がかかっている状態だと制御不能になるため、12V は最後まで残す）
- IGS 電源も PPX36-3 のため同じ VI 群を流用し、リファレンスだけ分ける。

## 6.6 CAN インタフェース

CAN は専用の検討が必要。[08_CAN通信の実装.md](./08_CAN通信の実装.md) を参照。

| VI | 処理概要 |
|----|----------|
| `CAN_Open.vi` | CAN セッション開始（dbc 読み込み） |
| `CAN_Send_Mode.vi` | 制御モード番号を CAN 送信（マイコン動作モード） |
| `CAN_Read.vi` | CAN フレーム受信・信号デコード |
| `CAN_Close.vi` | セッション終了 |
