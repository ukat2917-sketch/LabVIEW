## 各詳細手順に含めるもの

- 0～9の学習型標準構成
- 新規VIの保存場所
- フロントパネル制御器・表示器の作成
- コネクタペインの端子割当
- Case Structure、For Loop、Flat Sequence、Shift Registerの配置順
- 関数とSubVIのパレット位置
- 接続元、接続先、端子名、数値定数の型と値
- True / False / Enum全Caseの全出力
- 自動指標付けの有無とループ内外の型
- Shift Registerの左外側初期値、左内側、右内側更新値、右外側出力
- Original Error、Cleanup Error、Clear Errors、Merge Errorsの配線
- 正常、境界、Reject、Clamp、1ch、2ch、複数台、途中error、Cleanup error、既存errorのテスト

## 既決事項

次は変更しない。

- VI名
- typedef名とフィールド
- Wrapper / Service / PoCのレイヤ
- Output OFF → Load → Min/Max Query → Limit → Function → Frequency → Amplitude → Offsetの順序
- PrepareのInit → ID → PowerOn OFF → INDependent → NONEの順序
- PoCの1反復1台、Ch1 → Ch2、ON → Wait → OFF → Closeの順序
- Prepare内部でCloseせずPoC Cleanupへ一元化する方針
- Original ErrorをCleanup Errorより優先する方針
