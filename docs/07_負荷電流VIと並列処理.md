# 07. 負荷電流 VI と並列処理（割り込み可能設計）

負荷電流の変化（ランプ）は時間がかかるが、**変化中に他処理（モード遷移など）を割り込ませたい**。
そのため、負荷電流ランプ VI は **非同期・並列で動かせる設計** にする。

## 7.1 要求仕様

### 入力

| 入力 | 目的 |
|------|------|
| **開始電流値** | 現在の負荷状態を外部から指定し、どの電流から開始するかを条件管理 |
| **目標電流値** | 評価したい値を試験条件ごとに変更可能にする |
| **Ramp 時間** | 負荷変化速度そのものを評価パラメータとして扱う |
| 機器リファレンス in | 負荷電源（RZ-X）ハンドル |
| error in | エラークラスタ |

### 処理

- **指定時間での線形変化（ランプ）**：再現性の確保。
  開始電流値 → 目標電流値へ、Ramp 時間で直線的に変化させる。

### 出力

| 出力 | 用途 |
|------|------|
| **現在の出力電流値** | ログへの記録、TestStand での監視・条件分岐 |
| 実行結果ステータス | 完了／異常 |
| エラー情報 | トレース用 |

## 7.2 並列処理（割り込み可能）の実現方法

「ランプ中に他処理を割り込める」ようにするには、ランプ VI を **メイン処理と別スレッドで動かす**。
主に 2 通りの方式がある。

### 方式A：TestStand 側で非同期実行（推奨・シンプル）

- 負荷ランプ VI を **同期的に「開始→完了まで」動く 1 VI** として作る。
- TestStand 側で、その Sequence Call / Action ステップを **非同期（New Thread / Run in parallel）** で起動する。
- ランプ実行中に、メインシーケンスは次のステップ（CAN モード送信など）へ進む。
- ランプ完了は、TestStand の **Wait（Thread/Sequence の完了待ち）** ステップで同期させる。

> メリット：同期／非同期の切り替えを TestStand 側に集約できる（VI はシンプル）。
> 「同期／非同期は TestStand で管理」という本システムの方針と整合する。

### 方式B：LabVIEW 内で並列ループ（生産者・消費者／状態通知）

- ランプ VI を「開始」「現在値取得」「停止」に分割し、
  ランプ処理は **別の常駐ループ（並列 While ループ）** で実行する。
- 制御は **キュー / Notifier / FGV（Functional Global Variable）** で受け渡す。
  - `Load_Ramp_Start.vi`：開始電流・目標電流・Ramp 時間をキューに投入してランプ開始
  - `Load_Ramp_GetCurrent.vi`：現在の出力電流値を取得
  - `Load_Ramp_Stop.vi`：ランプ中断
- 並列ループは指定刻み（例：10〜50ms）ごとに電流値を計算して負荷電源へ設定し、
  現在値を FGV/Notifier で公開する。

> メリット：LabVIEW 内で ms オーダーの滑らかなランプができ、現在値もリアルタイムに取れる。
> デメリット：常駐ループの生存管理（起動・停止）が必要。

## 7.3 線形ランプの計算（コア処理）

```
刻み数 N = Ramp時間 / 制御周期Δt
各ステップ i (0..N):
   電流(i) = 開始電流値 + (目標電流値 - 開始電流値) * (i / N)
   → 負荷電源へ Current_Set
   → 現在値を出力 / ログ
   → 次の刻みまで待つ（制御周期Δt）
```

- 制御周期 Δt は機器の応答とスループットに合わせて決める（例：10ms）。
- Ramp 時間が 0 の場合はステップ的に目標値へ設定する分岐を入れておく。

## 7.4 推奨

- まずは **方式A（TestStand 非同期）** で構築するのが、本システムの役割分担方針
  （同期／非同期は TestStand 管理）と最も整合し、保守も容易。
- ランプ中の現在値をリアルタイムに監視・記録したい、または ms 精度の滑らかさが必要な場合は
  **方式B** を併用する。

## 7.5 割り込み処理の例（時系列）

```
t0: Load_Current_Ramp（0A→100A, 5秒）を非同期起動  ← 別スレッドで進行
t0+1s: CAN_Send_Mode（モード遷移）を実行            ← ランプ中に割り込み
t0+3s: RAMScope_Read / DLM波形確認                  ← ランプ中に計測
t0+5s: ランプ完了を待機（Wait）→ 同期点             ← ここで合流
t0+5s: 次ステップへ
```
